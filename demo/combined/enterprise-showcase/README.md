# Enterprise Operations Showcase (`enterprise-showcase`)

## What it is
The complete end-to-end flagship showcase combining all framework capabilities into a realistic cyber-physical operations platform:
1. Starts at a mock authentication gateway (`LoginPage.tsx`) with role selection (`admin`, `editor`, `viewer`).
2. Dual-rail navigation with deep modules and nested views.
3. Resizable `SplitWithInfoPanel` hosting the TanStack data table and properties sidebar.
4. Header with integrated `NotificationCenter`, language switcher, theme toggle, and customizer.
5. Live runtime role switcher demonstrating instant permission filtering across menus and actions.
