# ObjectPage Layout Template (`ObjectPage`)

## What it is
A modernized implementation of the enterprise entity overview Object Page design pattern.

## Features
- **Object Header**: Title, status badge, subtitle, and primary actions.
- **Key Attributes Bar**: High-density 4-column property summary.
- **Sticky Anchor Navigation**: Tabs that smoothly scroll to sections and remain sticky at the top during scrolling.
- **Sticky Footer Action Bar**: Fixed bottom bar for Save / Cancel actions with "unsaved changes" tracking.
