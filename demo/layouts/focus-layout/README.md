# FocusLayout Template (`FocusLayout`)

## What it is
A distraction-free, full-viewport layout designed for complex wizards, checkout/payment steps, and uninterrupted data entry.

## Features
- Completely removes the sidebars and global header navigation.
- Minimal top bar featuring a title, subtitle, and an exit/close button.
- Optional sticky bottom footer for Next / Finish / Cancel actions.
