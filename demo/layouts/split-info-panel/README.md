# SplitWithInfoPanel Layout Template (`SplitWithInfoPanel`)

## What it is
A flexible split layout hosting main content alongside a dedicated, collapsible, pinnable right information panel.

## Features
- **Switchable Ratios**: Quick-switch between `1/2` (50/50), `2/3 + 1/3` (66/34 default), and `3/4 + 1/4` (75/25).
- **Pinnable**: Toggle between pinned docked state and floating overlay state.
- **Collapsible**: Smooth collapse with persistent state.
- **Mobile Responsive**: On mobile viewports (<1024px), collapses to a bottom trigger button that slides up a touch-friendly Sheet drawer.
