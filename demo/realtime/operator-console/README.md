# Operator SCADA & Live Telemetry Console (`operator-console`)

## What it is
The cyber-physical control-room template:
- High-frequency live data streams with simulated sensor fluctuations.
- Quality indicators: good, uncertain, bad.
- `ConfirmHold`: Press-and-hold (1500ms) safety action for critical breakers.
- `ShiftModeToggle`: Day, Night, and High-Contrast Control Room presets.
- `TimeRangePicker`: Live, 15m, 1h, 6h, 24h.
