# Toast Notifications Gallery (`toasts`)

## What it is
The application toast notification system built on top of Sonner.

## Highlights
- **6 Live Positions**: `top-start`, `top-center`, `top-end`, `bottom-start`, `bottom-center`, `bottom-end`. Respects text direction (mirrored in RTL).
- **Variants**: `success`, `error`, `warning`, `info`, `promise`, `action ("Undo")`, `loading`.
- Avoids overlapping with bottom navigation bars and sticky action bars.
