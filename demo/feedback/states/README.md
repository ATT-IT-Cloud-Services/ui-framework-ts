# UI States & Placeholders (`states`)

## What it is
Comprehensive presentation states:
1. `EmptyState`: Clean illustration, title, description, and primary CTA.
2. `ErrorState`: Error details, technical stack toggle, and retry callback.
3. `InfoCard`: 5 semantic variants (`info`, `success`, `warning`, `error`, `promo`).
4. Skeletons: Table, Dashboard, MasterDetail, and ObjectPage loaders.
