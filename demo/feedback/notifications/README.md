# Notification Center & Banners (`notifications`)

## What it is
Comprehensive alerting and notification surfaces:
1. `NotificationCenter`: Popover (Sheet on mobile) with All, Unread, and Mentions tabs, grouped by day, mark-all-read.
2. `AnnouncementBanner`: Global dismissible banner with variants (`info`, `warning`, `promo`, `maintenance`) and persisted dismissal.
3. `InlineAlert`: Compact alert boxes.
4. `ProgressToast`: Asynchronous upload/task progress indicator.
5. `ConnectionStatusBanner`: Live network telemetry status indicator.
