# Popovers & Floating Overlays (`popovers`)

## What it is
Floating UI components:
1. `FilterPopover`: Dedicated popover with clear/apply controls and active badge counters.
2. `QuickActionsMenu`: Fixed speed-dial Floating Action Button (FAB).
3. `Tour`: Step-by-step coachmark tutorial dialog.
4. `HoverCard`: Non-intrusive preview popover on link hover.
5. `ContextMenu`: Right-click contextual action menu (long-press on mobile).
