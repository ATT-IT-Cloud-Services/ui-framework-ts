# Internationalization & RTL Engine (`i18n-rtl`)

## What it is
The complete internationalization layer for the framework:
- Supported catalogs: English (`en`), German (`de`), French (`fr`), Spanish (`es`), Arabic (`ar`).
- Exact key parity across all 5 catalogs.
- Instant direction flipping between `ltr` and `rtl`.
- All spacing, margins, borders, and animations built using logical CSS properties (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`).
