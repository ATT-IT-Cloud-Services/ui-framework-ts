# Top Navigation (`topnav`)

## What it is
A horizontal navigation bar positioned directly below the application header. Features dropdown submenus, mega-menu 3rd-level support, and an automated overflow into a "More" dropdown when items exceed viewport width.

## When to use it
- Corporate portals, documentation, and reporting hubs where users prioritize full width for documents or data tables.
- Workspaces with a shallow hierarchy (3–8 main categories).
