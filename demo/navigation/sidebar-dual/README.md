# Dual Rail Navigation (`sidebar-dual`)

## What it is
A two-tier modular sidebar. The first 56px rail switches between primary top-level business modules (Operations, SCADA, Management, Configuration). The adjacent 200px panel displays all sub-views and nested routes of that selected module.

## When to use it
- Multi-suite applications (e.g., ERP + MES + SCADA) where each section has deep individual trees.
- Complex operations platforms where jumping between top-level modules needs to be distinct and clear.
