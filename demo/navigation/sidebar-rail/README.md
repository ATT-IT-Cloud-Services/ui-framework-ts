# Icon Rail Navigation (`sidebar-rail`)

## What it is
A 64px wide vertical icon rail. Features instant tooltips and nested submenus rendered as floating flyout popovers upon hover or click.

## When to use it
- Data-heavy screens, multi-column analytics, or code/diagram editors requiring maximum horizontal space.
- Expert users familiar with visual icons who prefer a distraction-free layout.

## Preset Settings
```typescript
{
  navigationMode: "sidebar-rail",
  navigationPosition: "start",
  sidebarState: "collapsed",
  headerSticky: true,
  showBreadcrumbs: true,
  contentWidth: "fluid",
  density: "compact"
}
```
