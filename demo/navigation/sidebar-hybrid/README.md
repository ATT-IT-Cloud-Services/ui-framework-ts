# Hybrid Sidebar Navigation (`sidebar-hybrid`)

## What it is
A dynamically switchable navigation sidebar that transforms between an icon rail and a full 260px expanded menu.

## Highlights
- Toggle with `Cmd+B` / `Ctrl+B` or top header toggle button.
- Remembers operator's preferred collapse state per route/demo.
- Supports optional hover expansion.

## Preset Settings
```typescript
{
  navigationMode: "sidebar-hybrid",
  navigationPosition: "start",
  sidebarState: "expanded",
  headerSticky: true,
  showBreadcrumbs: true,
  contentWidth: "fluid"
}
```
